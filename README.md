# 🎯 Rubika Challenge Bot

**Rubika Challenge Bot** یک ربات سرگرمی برای گروه‌های روبیکا است که با مجموعه‌ای از بیش از **۳۰۰ چالش آماده**، فضای گروه را سرگرم‌کننده‌تر و تعاملی‌تر می‌کند.

کاربران می‌توانند با استفاده از دستور مشخص، به‌صورت خودکار یک چالش دریافت کنند و آن را در گروه اجرا کنند.

## 📋 قابلیت‌ها

* 🔗 اتصال به گروه‌های روبیکا
* 🎯 بیش از **۳۰۰ چالش آماده**
* ⚡ دریافت چالش با دستور `چالش`
* 💬 پشتیبانی از **Reply**
* 🏷️ پشتیبانی از **Tag / Mention**
* 🤖 پاسخ‌دهی خودکار
* 🚀 پاسخ‌گویی سریع به درخواست‌ها
* 🎲 انتخاب خودکار چالش

## ⚙️ نحوه استفاده

برای دریافت یک چالش، کافی است ربات را **Reply** یا **Tag** کرده و دستور زیر را ارسال کنید:

```text
چالش
```

ربات به‌صورت خودکار یکی از چالش‌های موجود را انتخاب کرده و در گروه ارسال می‌کند.

## 🔄 نحوه عملکرد

```text
👤 کاربر
   │
   ├── Reply به ربات
   │       یا
   └── Tag کردن ربات
             │
             ↓
       ارسال «چالش»
             │
             ↓
      🎯 انتخاب چالش
             │
             ↓
       📤 ارسال در گروه
```

## 🎮 درباره پروژه

این پروژه با هدف ایجاد **تعامل بیشتر در گروه‌های روبیکا** و فراهم کردن یک سرگرمی ساده و سریع طراحی شده است.

وجود مجموعه بزرگی از چالش‌های آماده باعث می‌شود کاربران بتوانند در هر زمان یک چالش جدید دریافت کرده و از آن در جمع دوستان خود استفاده کنند.

## 🛠️ تکنولوژی

```text
Language: Python
Platform: Rubika
```

کتابخانه‌ها و وابستگی‌های موردنیاز پروژه در فایل `requirements.txt` قرار دارند.
